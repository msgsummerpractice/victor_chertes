Welcome! This repository contains all the planning materials for the *Cloud Training Program 2026* — a hands-on training designed for *students* to learn cloud-native development with Docker and Microsoft Azure.

=== What Students Will Learn

* How to containerize applications with *Docker*
* Cloud computing fundamentals and the *Azure* ecosystem
* Deploying frontends with *Azure Static Web Apps*
* Storing and versioning images with *Azure Container Registry*
* Running backends with *Azure Container Apps*
* Managing secrets with *Azure Key Vault*
* Monitoring your apps with *Azure Monitor* (logs, metrics, dashboards)
* Cloud career paths — Cloud Engineer, DevOps Engineer, Cloud Architect
